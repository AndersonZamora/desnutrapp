# 👶 KidsHealthTracker-Android

Aplicación móvil nativa Android para el seguimiento de salud infantil. Permite llevar el control de peso, el calendario de vacunas y el estado de salud general de los niños registrados.

---

## 📱 Características principales

- **Autenticación** — registro e inicio de sesión de usuarios con Firebase Authentication
- **Control de peso** — registro y seguimiento del peso del niño a lo largo del tiempo
- **Calendario de vacunas** — control de vacunas aplicadas y próximas fechas programadas
- **Estado de salud** — registro del estado general de salud del niño
- **Base de datos en tiempo real** — información sincronizada con Firebase

---

## 🛠️ Tecnologías utilizadas

| Categoría | Tecnología |
|---|---|
| Lenguaje | Java |
| UI | XML, RecyclerView, Fragments |
| Autenticación | Firebase Authentication |
| Base de datos | Firebase Realtime Database |
| IDE | Android Studio |
| Control de versiones | Git, GitHub |

---

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/AndersonZamora/KidsHealthTracker-Android.git

# Abrir en Android Studio
# File → Open → seleccionar la carpeta del proyecto

# Ejecutar en dispositivo o emulador
# Run → Run 'app'
```

> ⚠️ Requiere configurar un proyecto Firebase y agregar el archivo `google-services.json` en la carpeta `/app`.

---

## 📋 Requisitos

- Android 6.0 (API 23) o superior
- Conexión a internet
- Cuenta Firebase configurada
